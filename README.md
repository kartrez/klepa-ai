# 🚀 Klepa AI

> Klepa AI — это универсальная агентная платформа для ИИ-инженерии. Стройте, поставляйте и итерируйте быстрее с помощью самого популярного опенсорсного агента для программирования.

Klepa AI превращает вашу среду разработки в мощную платформу, где ИИ-агенты помогают вам не только писать код, но и понимать архитектуру, проводить рефакторинг, писать тесты и автоматизировать рутинные задачи.

## ✨ Основные возможности

- **Автономные агенты**: Мощные агенты, способные выполнять сложные инженерные задачи.
- **Индексация кода**: Умный поиск и понимание контекста всего вашего проекта.
- **Интеграция с MCP**: Поддержка Model Context Protocol для расширения возможностей агентов.
- **Поддержка множества LLM**: Работайте с OpenAI, Anthropic, Google Gemini, Ollama и другими провайдерами.
- **Безопасность**: Полный контроль над тем, какие файлы доступны агенту.
